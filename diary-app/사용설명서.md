# 업무다이어리 사용설명서

## ✅ 처음 설정, 전체 순서 (한 번만)

| 순서 | 할 일 | 자세한 설명 |
|---|---|---|
| 1 | 설치 파일 받기 (GitHub → Releases 또는 Actions) | 1장 |
| 2 | 맥에 설치하고 처음 열기 (경고 → "그래도 열기") | 2장 |
| 3 | 앱 SETTING → 연결 → **노션으로 로그인** → 브라우저에서 **허용** | 3장 |
| 4 | (선택) Claude Code 설치·로그인 → 렌과 대화 (구독 그대로, 크레딧 X) | 4장 |
| 5 | (선택) 렌 표정 6장 올리기 · 비서 지침 넣기 | 4-1, 4-2장 |

설정 화면은 앱 오른쪽 위 빨간 **SETTING** 버튼이에요.

## 1. 설치 파일 받기 (GitHub가 자동으로 만들어 줘요)

> 가장 쉬운 곳: 저장소 첫 화면 오른쪽 **Releases** → 맨 위 버전 → **Assets**에서 `…mac-arm64.dmg`(M1~M4) 또는 `…mac-x64.dmg`(인텔) 받기. 아래는 Actions에서 받는 방법이에요.

코드를 올리면 GitHub가 Mac 설치 파일(.dmg)을 알아서 만들어요. 다 만들어지는 데 10분쯤 걸려요.

1. 인터넷 브라우저에서 GitHub 저장소 **foreverclosemyeyes/dunno** 를 열어요.
2. 위쪽 메뉴에서 **Actions** 를 눌러요.
3. 목록 맨 위의 **"업무다이어리 설치 파일 만들기"** 를 눌러요.
   - 초록색 ✓ 표시면 완성, 노란 동그라미는 만드는 중이에요(기다리기).
4. 화면 맨 아래 **Artifacts** 에서 **WorkDiary-macOS** 를 눌러 내려받아요.
5. 받은 zip 파일을 더블클릭해서 풀면 .dmg 파일이 2개 나와요. 내 Mac에 맞는 것을 골라요.
   - 왼쪽 위 사과() 메뉴 → **이 Mac에 관하여** → "칩"이 **Apple M1/M2/M3/M4** 이면 `...-mac-arm64.dmg`
   - "프로세서"가 **Intel** 이면 `...-mac-x64.dmg`

> 💡 나중에 이 저장소의 main 브랜치에 합친 뒤에는 Actions 화면 오른쪽의 **Run workflow** 버튼으로도 만들 수 있어요.
> 이렇게 만들면 저장소 첫 화면 오른쪽 **Releases** 에도 설치 파일이 올라가서 받기가 더 편해요.

## 2. Mac에 설치하고 처음 열기

1. .dmg 파일을 더블클릭 → 나온 창에서 **WorkDiary** 아이콘을 **Applications(응용 프로그램)** 폴더로 끌어다 놓아요.
2. 응용 프로그램 폴더에서 **WorkDiary** 를 더블클릭해요.
3. 이 앱은 애플 유료 인증을 받지 않은 개인용 앱이라 처음 한 번은 경고가 떠요.
   - "확인할 수 없습니다" 경고가 뜨면 → **완료** 를 눌러 닫아요.
   - **시스템 설정 → 개인정보 보호 및 보안** 으로 가서 맨 아래쪽 *"업무다이어리"이(가) 차단되었습니다* 옆의 **그래도 열기** 를 눌러요. Mac 비밀번호를 넣으면 열려요.
   - 만약 **"손상되었기 때문에 열 수 없습니다"** 라고 나오면: **터미널** 앱(Spotlight에서 "터미널" 검색)을 열고 아래 한 줄을 붙여 넣은 뒤 Enter, 다시 앱을 열어요.
     ```
     xattr -cr /Applications/WorkDiary.app
     ```
4. **알림 허용**: 처음에 알림 허용을 물어보면 **허용**. 놓쳤다면 **시스템 설정 → 알림 → 업무다이어리 → 알림 허용** 을 켜요.

## 3. 노션 연결하기

### 방법 A. 노션으로 로그인 (추천 · 회사 관리자 권한 없어도 됨)
1. 앱 **SETTING → 연결 → 노션 연결 → "노션으로 로그인"** 클릭
2. 브라우저에 노션 화면이 열려요 → **Buzz & Beyond** 워크스페이스 고르고 **허용**
3. "노션 연결 완료!" 화면이 뜨면 그 창은 닫고 앱으로 돌아오기 — 끝!
4. 확인하고 싶으면 **연결 테스트** → "연결 성공!"
- 체크리스트·진행 중 업무·일정이 2분마다 불러와지고, 앱에서 체크하면 노션에도 체크돼요
- 로그인이 풀리면(가끔) 같은 버튼을 다시 누르면 돼요

### 방법 B. 노션 내부 통합 키 (회사에서 키를 만들 수 있을 때만)
노션 **설정 → 연결 → 개발** 화면에서 "내부 연결을 생성할 권한이 없습니다"라고 나오면 이 방법은 못 써요 → 방법 A를 쓰세요.
1. notion.so/profile/integrations → 새 API 통합 → 내부 · 기능: 콘텐츠 읽기 + 업데이트 → 시크릿(ntn_…) 복사
2. 앱 SETTING → 연결 → **노션 내부 통합 키**에 붙여넣고 저장
3. 노션에서 **경영지원_Tasks** DB 열기 → ••• → **연결** → 만든 통합 추가

## 4. 렌과 대화하기 (이미 쓰는 Claude 구독으로 — 크레딧 필요 없음)

앱이 이 맥에 설치된 **Claude Code**를 통해, 지금 쓰고 계신 **Claude 구독**으로 렌이 대답하게 해요. API 크레딧은 안 써요(구독 사용량으로 계산돼요).

1. **터미널** 앱 열기 (Spotlight에서 "터미널" 검색)
2. 아래 한 줄을 붙여 넣고 Enter → 설치가 끝날 때까지 기다리기
   ```
   curl -fsSL https://claude.ai/install.sh | bash
   ```
3. 터미널에 `claude` 입력 → Enter → 안내에 따라 **Claude 계정으로 로그인** (구독 계정) → 로그인되면 터미널은 닫아도 돼요
4. 업무다이어리를 **완전히 종료했다가 다시 켜기** (메뉴 막대 아이콘 → 완전히 종료)
5. 렌 말풍선 아래에 **답하는 칸**이 생겨요 → 질문 쓰고 Enter

- 설치·로그인이 안 돼 있으면 렌은 정해진 문장으로만 말해요(무료 모드)
- (선택) API 크레딧을 쓰고 싶으면 SETTING → 연결 → Anthropic API 키에 넣어도 돼요. 키가 있으면 키가 우선이에요

### 4-1. Claude의 "업무비서" 채팅과 맞추기
claude.ai에 만들어 둔 업무비서 채팅방을 이 앱에 그대로 이어 붙일 수는 없어요. Claude가 채팅 기록을 다른 앱에 열어 주지 않기 때문이에요.
대신 **똑같은 성격·규칙으로 말하게** 하고, 버튼 하나로 그 채팅방을 열 수 있게 해 뒀어요.
1. claude.ai에서 업무비서 **프로젝트 → 지침(Instructions)** 내용을 전부 복사해요. 프로젝트가 아니라 채팅에서 정한 규칙이면 그 규칙을 정리해서 복사해요.
2. 앱 **⚙ → 비서 → 업무비서 지침** 칸에 붙여 넣어요.
3. 브라우저 주소창의 업무비서 채팅 주소(`https://claude.ai/...`)를 **Claude 채팅 주소** 칸에 붙여 넣고 **저장**.
4. 이제 앱의 비서가 그 지침과 오늘 노션 업무를 보고 대답해요. 비서 칸의 **Claude에서 열기**(또는 메뉴 막대 아이콘)로 그 채팅방이 바로 열려요.
   - 앱 안에서 나눈 대화는 앱에 저장되고, 최근 30개 메시지를 기억해서 이어서 대화해요.
5. **지침·채팅 주소·모델은 비서마다 따로** 저장돼요. 예를 들어 한 비서에는 GMEP 채팅의 지침과 주소를, 다른 비서에는 유연근무 채팅의 지침과 주소를 넣어 두세요. 말풍선의 이름을 누르면 다음 비서로 바뀌고, 그 비서의 지침으로 대답해요. 대화도 비서별로 따로 이어져요(대화 기록 화면에는 전부 보여요).

---

### 4-2. 비서 캐릭터 (표정 6가지) · 회사에서 숨기기
1. ⚙ → **비서** → **캐릭터 그림** 칸 6개(기본 / 말하기 / 웃음 / 윙크 / 진지 / 눈감음)를 눌러 그림을 하나씩 올려요.
   **여러 장 한 번에 올리기**로 6장을 그 순서대로 한꺼번에 올려도 돼요. 투명 배경 PNG/WebP를 추천해요.
2. 비서가 말할 때는 입이 움직이고(기본↔말하기), 가만히 있을 때는 가끔 눈을 깜빡여요.
   Claude가 대답에 맞춰 표정을 골라요(마감 경고 → 진지, 좋은 소식 → 웃음 등).
3. 그림은 이 컴퓨터에만 저장되고 GitHub에는 올라가지 않아요.
4. **숨기기**
   - 위쪽 **HIDE** 버튼 또는 **Option + H**: 캐릭터만 바로 숨기기/보이기
   - **⌘ + Shift + X**(바꿀 수 있음): 다른 프로그램을 쓰는 중이어도 업무다이어리 창 전체를 바로 숨기고, 한 번 더 누르면 다시 보여요.
     ⚙ → 비서 → **회사에서 숨기기**에서 단축키를 바꾸거나 끌 수 있어요.

### 4-3. Gmail 맡기기 (메일 읽기 · 임시보관함에 초안 쓰기)

비서에게 "○○에게 온 메일 찾아 줘", "답장 초안 써 줘"처럼 말할 수 있어요. 비서는 메일을 **읽고 임시보관함에 초안만** 넣어요. **보내기·지우기는 못 하게 막아 뒀고**, 보내는 건 Gmail에서 직접 하세요.

1. claude.ai 설정의 **커넥터**에서 Gmail을 연결해요. (맥의 Claude Code에 로그인한 것과 같은 계정)
2. 앱의 **SETTING → 연결 → Gmail**에서 **Gmail 사용**을 켜요.
3. **Gmail 연결 확인**을 눌러요. 최근 메일 한 통의 제목이 뜨면 된 거예요. 안 되면 이유가 그 자리에 떠요.

Gmail은 Claude 구독 로그인에서만 쓸 수 있어서, 켜 두면 대화는 항상 맥의 Claude Code로 답해요.

## 5. 저장소 비공개 + 앱 안 업데이트

### 5-1. 저장소 비공개로 바꾸기
1. GitHub에서 **foreverclosemyeyes/dunno** → 위쪽 **Settings**
2. 맨 아래 빨간 **Danger Zone** → **Change repository visibility** → **Make private** → 안내대로 저장소 이름 입력해서 확인

### 5-2. GitHub 열쇠(토큰) 만들기 — 비공개일 때만 필요
1. **github.com/settings/personal-access-tokens/new** 열기 (앱 SETTING → 연결 → 업데이트 → **열쇠 만들기 페이지 ↗** 버튼으로도 열려요)
2. 이렇게 채워요
   - **Token name**: `업무다이어리 업데이트`
   - **Expiration**: `No expiration`(만료 없음) 또는 1년
   - **Repository access**: **Only select repositories** → `foreverclosemyeyes/dunno` 하나만 고르기
   - **Permissions → Repository permissions → Contents**: **Read-only**
3. 맨 아래 **Generate token** → 나온 `github_pat_…` 글자 **복사** (창을 닫으면 다시 못 봐요)
4. 앱 **SETTING → 연결 → 업데이트 → GitHub 열쇠** 칸에 붙여 넣고 **저장**

### 5-3. 업데이트 하는 법
- 새 버전이 나오면 앱 위쪽에 **● UPDATE v1.0.xx** 버튼이 생겨요 (앱이 켜질 때, 그리고 6시간마다 확인)
- 누르고 **확인** → 받아서 바꿔 끼운 뒤 앱이 다시 켜져요. 설정·테마·키·렌 그림은 그대로예요
- 앱이 **응용 프로그램 폴더**에 있어야 해요 (dmg 창 안에서 바로 켠 상태에선 안 돼요)
- 바로 확인하고 싶으면 SETTING → 연결 → 업데이트 → **지금 확인**
- ⚠ 이 업데이트 기능은 **이번 버전부터** 들어가요. 그래서 이번 한 번만 1장처럼 직접 받아서 설치해 주세요

| 인간 파라미터 | **자동**: 체크리스트를 완료하면 일의 성격을 보고 지식/배짱/손재주/친절/매력 중 하나가 +1 되고 **POINT UP!!** 이 떠요. 달마다 누적돼서 등급 1~5가 오르면 **RANK UP!!** 과 함께 등급 이름(페르소나 5 로열 이름, 예: 지식 Oblivious → Learned → Scholarly → Encyclopedic → Erudite)이 바뀌어요. 노트의 **파라미터** 탭에서 큰 별로 보고, 이름표에 마우스를 올리면 + / − 로 고칠 수 있어요 |

- **노트**: 종이가 두 장이에요. 위 종이는 오늘의 기록(오른쪽 탭으로 **기록 / 파라미터** 넘기기), 아래 종이는 진행 중 업무(마감 가까운 순)예요
- **달력 점**: 꽉 찬 점 = 그날 다 끝냄, 빈 동그라미 = 남은 일 있음
- **일정 표시**: 노션 "기간"이 있는 내 업무가 숫자 아래에 ●(하루), ●—●(여러 날)로 작은 회색 점과 가는 회색 선으로 표시돼요(레퍼런스처럼). 한 주에 하나만(미팅·세미나 먼저, 그다음 마감이 가까운 것) 그리고, 7일보다 긴 업무는 날짜를 눌렀을 때 일정 버튼으로만 보여요. Tags가 meeting·seminar면 포인트 색. ⚙ → 색·배치 → 레이아웃에서 "meeting·seminar만"으로 바꿀 수 있어요
- **진행 중 업무 강조**: 마감 3일 이내는 주황 줄, 마감이 지나면 `D+숫자`
- **창을 닫아도(✕) 꺼지지 않아요.** 화면 위쪽 메뉴 막대의 달력 아이콘에 남아서 정시 알림을 보내요.
  완전히 끄려면 메뉴 막대 아이콘 → **완전히 종료**.
- **매시간 체크**: 평일 9시~19시 정시마다 오늘 남은 일·끝낸 일·마감 임박 업무를 보고 알림과 비서 칸으로 말 걸어요. (Anthropic 키를 넣었을 때만 비서 칸이 보이고 동작해요)
- **자정이 지나면** 날짜·이번 주 띠·달력·체크리스트가 저절로 새 날로 바뀌어요. 월요일엔 새 주차 운영성 업무 페이지를 다시 찾아요.
- **컴퓨터 켜면 자동 실행**: ⚙ → 연결 → 일반에서 켜고 끌 수 있어요. (기본 켜짐, 켜질 때는 메뉴 막대에 조용히 켜져요)

## 꾸미기 (SETTING)

바꾸는 즉시 화면에 보이고, 앱을 껐다 켜도 그대로예요.

- **글씨 탭**: 큰 날짜 숫자 / 월·요일 / 섹션 제목 / 체크리스트 / 진행 중 업무 / 비서 메시지 / 본문을 하나씩 골라 꾸며요.
  - 글씨체: 이름을 쓰면 목록이 떠요. **내 컴퓨터** = 설치된 글씨체 불러오기, **파일 올리기** = .ttf/.otf 추가
  - 굵기: 가변 글씨체면 100~900 사이 아무 값, 아니면 있는 굵기 중에서 골라요
  - 크기·자간·행간·세로 길이·가로 폭·회전(기준점)·기울임·글자별 회전·색·외곽선·그림자·대문자·밑줄
- **색·배치 탭**: 색 5가지(투명도 포함), 달력 기울기(기본 -4°), 카드 기울기, 사선 띠 각도·두께·위치, 질감 세기
- **배경 탭**: 단색 / 그라데이션 / 이미지 / 동영상(mp4·webm). 채우기 방식, **드래그로 옮기기**, 확대·회전, 밝기·흐림·투명도·색 덮개.
  "요일별로 다르게" 또는 "여러 장을 시간마다 바꾸기"도 돼요.
- **비서 탭**: 이름, 말투, 캐릭터 그림(투명 배경 PNG 추천), 크기·위치
- **테마 탭**: 지금 꾸밈을 이름 붙여 저장·불러오기, **파일로 내보내기/가져오기** (글씨체·그림·동영상까지 한 파일에 담겨요)
- 슬라이더 옆 숫자 칸에 직접 입력 가능, 각 줄 오른쪽 **↺** = 그 항목만 기본값으로
- 위쪽 **↶ ↷** = 실행 취소 / 다시 실행 (⌘Z / ⌘⇧Z)

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| "노션에 체크하지 못했어요" | 3-1의 **콘텐츠 업데이트** 권한을 켰는지 확인 |
| "노션 DB를 찾을 수 없어요" | 3-2 연결(Connections)을 했는지 확인 |
| "노션 키가 올바르지 않아요" | 3-1에서 키를 다시 복사해 ⚙ → 연결에 저장 |
| 체크리스트가 안 보임 | 그 주 페이지 이름에 **"운영성 업무"** 가 들어 있는지, 기간에 오늘이 포함되는지 확인. 날짜 제목은 `11/10 (화)` 모양이어야 해요 |
| 알림이 안 옴 | 시스템 설정 → 알림 → 업무다이어리 → 허용 / 집중 모드 꺼져 있는지 / 매시간 체크 켜져 있는지 |
| 비서가 "기본 문장"으로만 말함 | Anthropic 키가 없거나 크레딧 부족. ⚙ → 연결 확인 |

## 저장 위치 (참고)

모든 설정·테마·인간 파라미터·올린 파일은 이 Mac의 `~/Library/Application Support/WorkDiary/` 에 저장돼요.
API 키는 여기에 **암호화**돼서 들어 있어요. 노션에는 체크박스 체크/해제만 써요.

### (개발용) 내 Mac에서 바로 실행해 보기
Node.js 22(https://nodejs.org 의 LTS)를 설치한 뒤 터미널에서:
```
cd diary-app
npm install
npm start          # 앱 실행
npm test           # 노션 체크리스트 읽기 테스트
npm run dist:mac   # 내 Mac에서 직접 .dmg 만들기 (dist 폴더에 생김)
```
