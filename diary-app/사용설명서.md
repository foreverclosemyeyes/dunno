# 업무다이어리 사용설명서

노션 `경영지원_Tasks`의 체크리스트와 퀘스트를 옆에 띄워 두고 보는 Mac용 다이어리 앱이에요.
처음 한 번만 아래 1~4단계를 순서대로 하면 돼요. (전부 해도 20~30분 정도)

---

## 1. 설치 파일 받기 (GitHub가 자동으로 만들어 줘요)

코드를 올리면 GitHub가 Mac 설치 파일(.dmg)을 알아서 만들어요. 다 만들어지는 데 10분쯤 걸려요.

1. 인터넷 브라우저에서 GitHub 저장소 **foreverclosemyeyes/dunno** 를 열어요.
2. 위쪽 메뉴에서 **Actions** 를 눌러요.
3. 목록 맨 위의 **"업무다이어리 설치 파일 만들기"** 를 눌러요.
   - 초록색 ✓ 표시면 완성, 노란 동그라미는 만드는 중이에요(기다리기).
4. 화면 맨 아래 **Artifacts** 에서 **WorkDiary-macOS** 를 눌러 내려받아요.
5. 받은 zip 파일을 더블클릭해서 풀면 .dmg 파일이 2개 나와요. 내 Mac에 맞는 것을 골라요.
   - 왼쪽 위 사과() 메뉴 → **이 Mac에 관하여** → "칩"이 **Apple M1/M2/M3/M4** 이면 `...-mac-arm64.dmg`
   - "프로세서"가 **Intel** 이면 `...-mac-x64.dmg`

> 💡 나중에 이 저장소의 main 브랜치에 합친 뒤에는 Actions 화면 오른쪽의 **Run workflow** 버튼으로도 만들 수 있어요.
> 이렇게 만들면 저장소 첫 화면 오른쪽 **Releases** 에도 설치 파일이 올라가서 받기가 더 편해요.

## 2. Mac에 설치하고 처음 열기

1. .dmg 파일을 더블클릭 → 나온 창에서 **업무다이어리** 아이콘을 **Applications(응용 프로그램)** 폴더로 끌어다 놓아요.
2. 응용 프로그램 폴더에서 **업무다이어리** 를 더블클릭해요.
3. 이 앱은 애플 유료 인증을 받지 않은 개인용 앱이라 처음 한 번은 경고가 떠요.
   - "확인할 수 없습니다" 경고가 뜨면 → **완료** 를 눌러 닫아요.
   - **시스템 설정 → 개인정보 보호 및 보안** 으로 가서 맨 아래쪽 *"업무다이어리"이(가) 차단되었습니다* 옆의 **그래도 열기** 를 눌러요. Mac 비밀번호를 넣으면 열려요.
   - 만약 **"손상되었기 때문에 열 수 없습니다"** 라고 나오면: **터미널** 앱(Spotlight에서 "터미널" 검색)을 열고 아래 한 줄을 붙여 넣은 뒤 Enter, 다시 앱을 열어요.
     ```
     xattr -cr /Applications/업무다이어리.app
     ```
4. **알림 허용**: 처음에 알림 허용을 물어보면 **허용**. 놓쳤다면 **시스템 설정 → 알림 → 업무다이어리 → 알림 허용** 을 켜요.

## 3. 노션 연결하기 (읽기 전용)

### 3-1. 노션 통합(Integration) 키 만들기
1. 브라우저에서 **https://www.notion.so/profile/integrations** 를 열어요. (노션 로그인 상태여야 해요)
2. **새 통합(+ New integration)** 을 눌러요.
3. 이렇게 채워요.
   - 이름: `업무다이어리` (아무 이름이나 OK)
   - 워크스페이스: **Buzz & Beyond**
   - 유형: **내부(Internal)**
4. **저장** → 다음 화면의 **기능(Capabilities)** 에서
   - ✅ **콘텐츠 읽기** 만 켜고, *콘텐츠 업데이트/삽입* 은 꺼요. (앱은 읽기만 해요)
   - 사용자 정보: **이메일 없이 사용자 정보 읽기**
   - 바꿨으면 **저장**.
5. **내부 통합 시크릿(Internal Integration Secret)** 의 **표시 → 복사** 를 눌러요. (`ntn_` 으로 시작하는 긴 글자)

> ⚠ "새 통합" 버튼이 안 보이면 워크스페이스 관리자만 만들 수 있게 설정된 거예요. 관리자에게 "읽기 전용 내부 통합 하나 만들어 달라"고 부탁하면 돼요.

### 3-2. 통합을 DB에 연결하기 (Connections)
키만 만들면 아직 아무 페이지도 못 봐요. **경영지원_Tasks DB에 이 통합을 초대**해야 해요.
1. 노션에서 **경영지원_Tasks** 데이터베이스를 **전체 페이지로** 열어요.
   (경영지원 Home → 별도DB → 경영지원_Tasks. 표 제목 옆 ↗ 를 누르면 전체 페이지로 열려요)
2. 오른쪽 위 **•••** (점 3개) → **연결(Connections)** → 검색창에 `업무다이어리` 입력 → 선택 → **확인**.
3. 이렇게 하면 DB 안의 모든 업무 페이지(운영성 업무 페이지 포함)를 앱이 읽을 수 있어요.

### 3-3. 앱에 키 넣기
1. 앱 오른쪽 위 **⚙** → **연결** 탭
2. **노션 내부 통합 키** 칸에 붙여 넣고 **저장**
3. **연결 테스트** → "연결 성공!" 이 나오면 끝. 몇 초 뒤 체크리스트와 퀘스트가 떠요.
   - 키는 Mac 키체인으로 암호화돼서 저장되고, 화면에는 다시 보이지 않아요.
   - DB ID·내 노션 ID는 미리 넣어 뒀어요. 바꿀 일은 거의 없어요.

## 4. AI 비서 키 넣기 (선택)

키가 없어도 비서는 기본 문장으로 말해 줘요. 진짜 AI처럼 말하게 하려면 Anthropic 키를 넣어요.

1. **https://console.anthropic.com** 에서 가입/로그인해요.
2. **Settings → Billing** 에서 크레딧을 충전해요. (최소 $5, 선불)
   - 💰 **요금 안내**: 쓴 만큼만 크레딧에서 빠져요. 이 앱은 가볍고 빠른 **Claude Haiku 5.5** 를 써서
     한 번 말 걸 때 1원도 안 들어요. 평일 매시간 체크를 켜도 **한 달에 대략 100원 안팎**이에요.
   - 걱정되면 **Settings → Limits** 에서 월 사용 한도를 정해 둘 수 있어요.
3. **Settings → API Keys → Create Key** → 이름 `업무다이어리` → 만들어진 키(`sk-ant-...`)를 **복사**. (이 화면을 닫으면 다시 못 봐요)
4. 앱 **⚙ → 연결 → Anthropic API 키** 에 붙여 넣고 **저장** → 아래 **지금 확인해줘** 로 시험해 봐요.

## 매일 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 다른 날 체크리스트 보기 | 왼쪽 이번 주 띠나 달력의 날짜 누르기 |
| 오늘로 돌아오기 | 오른쪽 위 **오늘로** 버튼 |
| 노션에서 바로 고치기 | 기록 카드의 **노션에서 열기**, 퀘스트는 줄을 누르면 열려요 |
| 바로 새로고침 | 오른쪽 위 **⟳** (자동으로는 2분마다) |
| 다른 창 위에 늘 띄우기 | 오른쪽 위 **📌** |
| 비서에게 물어보기 | **지금 확인해줘** |
| 능력치 올리기 | 오른쪽 아래 **+** (실수하면 **−**). 고른 날짜에 쌓이고, 막대는 그 달 누적 |

- **달력 점**: 꽉 찬 점 = 그날 다 끝냄, 빈 동그라미 = 남은 일 있음
- **퀘스트 강조**: 마감 3일 이내는 주황 줄, 마감이 지나면 `D+숫자`
- **창을 닫아도(✕) 꺼지지 않아요.** 화면 위쪽 메뉴 막대의 달력 아이콘에 남아서 정시 알림을 보내요.
  완전히 끄려면 메뉴 막대 아이콘 → **완전히 종료**.
- **매시간 체크**: 평일 9시~19시 정시마다 오늘 남은 일·끝낸 일·마감 임박 업무를 보고 알림 + 말풍선으로 말 걸어요.
- **자정이 지나면** 날짜·이번 주 띠·달력·체크리스트가 저절로 새 날로 바뀌어요. 월요일엔 새 주차 운영성 업무 페이지를 다시 찾아요.
- **컴퓨터 켜면 자동 실행**: ⚙ → 연결 → 일반에서 켜고 끌 수 있어요. (기본 켜짐, 켜질 때는 메뉴 막대에 조용히 켜져요)

## 꾸미기 (⚙ 설정)

바꾸는 즉시 화면에 보이고, 앱을 껐다 켜도 그대로예요.

- **글씨 탭**: 큰 날짜 숫자 / 월·요일 / 섹션 제목 / 체크리스트 / 퀘스트 / 비서 말풍선 / 본문을 하나씩 골라 꾸며요.
  - 글씨체: 이름을 쓰면 목록이 떠요. **내 컴퓨터** = 설치된 글씨체 불러오기, **파일 올리기** = .ttf/.otf 추가
  - 굵기: 가변 글씨체면 100~900 사이 아무 값, 아니면 있는 굵기 중에서 골라요
  - 크기·자간·행간·세로 길이·가로 폭·회전(기준점)·기울임·글자별 회전·색·외곽선·그림자·대문자·밑줄
- **색·배치 탭**: 색 5가지(투명도 포함), 달력 기울기(기본 -4°), 카드 기울기, 사선 띠 각도·두께·위치, 질감 세기
- **배경 탭**: 단색 / 그라데이션 / 이미지 / 동영상(mp4·webm). 채우기 방식, **드래그로 옮기기**, 확대·회전, 밝기·흐림·투명도·색 덮개.
  "요일별로 다르게" 또는 "여러 장을 시간마다 바꾸기"도 돼요.
- **비서 탭**: 이름, 말투, 캐릭터 그림(투명 배경 PNG 추천), 크기·위치
- **테마 탭**: 지금 꾸밈을 이름 붙여 저장·불러오기, **파일로 내보내기/가져오기** (글씨체·그림·동영상까지 한 파일에 담겨요)
- 슬라이더 옆 숫자 칸에 직접 입력 가능, 각 줄 오른쪽 **↺** = 그 항목만 기본값으로
- 위쪽 **↶ ↷** = 실행 취소 / 다시 실행 (⌘Z / ⌘⇧Z)

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| "노션 DB를 찾을 수 없어요" | 3-2 연결(Connections)을 했는지 확인 |
| "노션 키가 올바르지 않아요" | 3-1에서 키를 다시 복사해 ⚙ → 연결에 저장 |
| 체크리스트가 안 보임 | 그 주 페이지 이름에 **"운영성 업무"** 가 들어 있는지, 기간에 오늘이 포함되는지 확인. 날짜 제목은 `11/10 (화)` 모양이어야 해요 |
| 알림이 안 옴 | 시스템 설정 → 알림 → 업무다이어리 → 허용 / 집중 모드 꺼져 있는지 / 매시간 체크 켜져 있는지 |
| 비서가 "기본 문장"으로만 말함 | Anthropic 키가 없거나 크레딧 부족. ⚙ → 연결 확인 |

## 저장 위치 (참고)

모든 설정·테마·능력치·올린 파일은 이 Mac의 `~/Library/Application Support/업무다이어리/` 에 저장돼요.
API 키는 여기에 **암호화**돼서 들어 있어요. 노션에는 아무것도 쓰지 않아요(읽기만 함).

### (개발용) 내 Mac에서 바로 실행해 보기
Node.js 22(https://nodejs.org 의 LTS)를 설치한 뒤 터미널에서:
```
cd diary-app
npm install
npm start          # 앱 실행
npm test           # 노션 체크리스트 읽기 테스트
npm run dist:mac   # 내 Mac에서 직접 .dmg 만들기 (dist 폴더에 생김)
```
