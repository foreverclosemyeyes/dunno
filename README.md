# 등불식당

호숫가 마을의 작은 식당을 물려받은 주인공이, 낮에는 밭을 일구고 물고기를 낚고,
밤에는 길 잃은 혼령 손님에게 **기억 속 그 맛**을 차려 주는 도트 게임.
혼령이 원하는 요리를 맞히면 호숫가 석등에 불이 켜지고, 여덟 개를 모두 밝히면 등불 축제가 열립니다.

`index.html`을 브라우저로 열면 바로 됩니다 (설치 없음). 그림·소리는 전부 코드로 만듭니다.

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 걷기 |
| 스페이스 / E | 상황에 맞는 행동 (땅 갈기, 심기, 물 주기, 수확, 손님 맞이…). 낚시·불 조절은 꾹 누르기 |
| Q | 뿌릴 씨앗 바꾸기 |
| 꾹 누른 채 걷기 | 밭 갈기·심기·물 주기를 한 줄 내리 반복 |
| Tab / I | 바구니 (요리 수첩, 손님 수첩, 물고기 도감) |
| M | 음악 켜기/끄기 |

휴대폰은 조이스틱 + A 버튼.

## 구조
- `js/art.js` — 팔레트, 구체 음영(`shadeEll`), 부드러운 외곽선(`outline`), 캐릭터 조합, 나무·건물·작물·아이콘
- `js/dishes.js` — 요리 완성 그림과 손질용 재료 그림
- `js/data.js` — 작물, 물고기, 요리 레시피, 혼령 이야기
- `js/world.js` — 지도 생성과 픽셀 단위 지형 굽기
- `js/cook.js` — 실제 조리 순서대로 하는 요리 (씻기·껍질 벗기기·썰기·물 붓기·끓이기·풀기·볶기·졸이기·간 보기·굽기·뜸 들이기·담기 등). 냄비 상태가 단계를 넘어 이어짐
- `js/game.js` — 게임 본체 (농사, 낚시, 손님, 하루, 그리기)
- `js/ui.js`, `js/audio.js` — 화면 UI, 소리

## Tide (기분·수면 기록 앱)
`mood/` 폴더에 있는 별도의 개인용 웹앱(PWA). 서버 없이 기기 안에만 기록을 저장합니다.
