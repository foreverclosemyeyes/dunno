# 솔바람 농장

밭 갈고, 낚시하고, 요리하는 작은 도트 게임. 설치 없이 `index.html`을 브라우저로 열면 바로 됩니다.
그림은 전부 코드로 찍은 16×16 도트이고, 외부 이미지 파일은 없습니다.

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 걷기 |
| 스페이스 / E | 바라보는 칸에 행동 (도구, 수확, 대화, 먹기) |
| 1 ~ 0, 휠, Q | 도구막대 선택 |
| Tab / I | 가방 (칸 두 번 눌러 자리 바꾸기, 저장) |
| M | 음악 켜기/끄기 |

휴대폰에서는 화면 조이스틱과 A 버튼으로 합니다.

## 할 수 있는 것
- **농사**: 순무(3일) · 당근(4일) · 토마토(5일, 다시 열림) · 호박(7일). 물 준 날만 자라고, 비 오는 날은 자동으로 물이 줘집니다.
- **낚시**: 찌가 잠기면(!) 바로 행동 키, 그다음 움직이는 바늘이 초록 칸에 올 때 맞춰 누릅니다. 3번 빗나가면 줄이 끊어집니다.
  붕어 · 송어(오전) · 메기(비/밤) · 황금잉어(선착장 끝 깊은 물).
- **요리**: 집 앞 솥에서 9가지 요리. 재료보다 비싸게 팔리고 기력을 많이 채워 줍니다.
- **채집**: 과일나무와 산딸기 덤불은 하루 한 번.
- **출하 상자**에 넣은 물건은 밤사이 팔립니다. 잠은 집 문에서 자고, 새벽 2시를 넘기면 쓰러집니다.
- 낮/저녁/밤 조명, 비, 반딧불, 배경음악(WebAudio로 즉석 생성), 자동 저장(브라우저 localStorage).
